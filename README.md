# Pacote de handoff — Landing de Mussarela 3G Foods

## Ordem recomendada

1. Abra `00_PROMPT_PARA_LOVABLE.md` e copie o conteúdo para iniciar a construção.
2. Use `01_BRIEFING_LOVABLE.md` como fonte de contexto, arquitectura, UX, dados configuráveis e critérios de aceitação.
3. Use `02_COPY_SEO_E_TESTES.md` para inserir copy, metadata, FAQ, eventos GA4/GTM e plano de experimentação.
4. Use `03_ASSETS_E_HANDOFF_VISUAL.md` para aplicar o hero e solicitar os materiais de produto que ainda faltam.
5. Copie os assets responsivos em `assets/` (hero desktop, mobile e logos transparentes em `assets/logos/`) para o armazenamento de assets do projecto.

## Antes de publicar

Confirme a URL real da categoria de mussarela, os destinos individuais, a lista de produtos, os dados comerciais, as fotografias oficiais, as condições por CEP e o tracking da compra. O pacote foi deliberadamente preparado para não preencher essas lacunas com informação inventada.
